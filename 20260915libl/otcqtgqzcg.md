# 月经紊乱、腹痛、多汗！流程什么样！

众所周知，诺雷德主要用于部分癌症的治疗，常见的有前列腺癌、乳腺癌、子宫内膜异位症、试管婴儿促排降调等，其临床应用比较广泛。因此往往会出现很多人在使用过程中出现一些不良反应，如腹痛、燥热、多汗等症状。为了让大家更好的了解该药，本文将对诺雷得副作用进行相关介绍，不清楚的朋友请接着往下看。

## 注射诺雷得的副作用

是药三分毒，大多数药品如果患者使用不正确都会出现一些不良反应。诺雷得也不例外，所以在使用的时候不但要了解诺雷得用法用量，还需要了解诺雷得禁忌，避免其副作用的发生。那么，下面一起来看看诺雷得究竟有哪些不良反应。

- 1. 血糖波动，对于很多男性患者，注射该药会有血糖增高、头晕、头痛的表现；
- 2. 血压异常，偶尔有病人注射本品之后会有高血压或者低血压，但这都是暂时性，能够在很短的时间恢复正常，不用停药；
- 3. 骨痛，病人注射该药之后可能出现短暂的骨骼疼痛，比如关节肿痛，需要对症治疗；
- 4. 乳腺症状，使用该药治疗乳腺癌早期时，可能会有加剧乳房疼痛、肿胀和乳头肿胀的表现，而且还可能导致血清钙的升高。

除此之外，男性患者在使用过程中可能会出现潮红、燥热、性功能下降的副作用，偶见乳房肿胀和硬结等不良反应。因此男性在使用的时候一定要注意，最好是在医生指导下使用。

而部分患者使用该药，还可能会导致骨质疏松等症状的出现。因为使用诺雷得以后，雌激素水平会下降，当严重减少的时候，骨代谢激素不足就会导致骨质疏松症的发生。

## 女性打诺雷德不良反应

女性使用诺雷德可能会产生一些副作用，如有的女性在用药之后可能会出现皮疹或者乳房胀痛，性欲减退等情况。有的女性可能会出现出汗，潮红，头痛或者情绪变化等症状。还有的女性可能会因为药物而出现月经紊乱，甚至月经等情况。

为了减少药物对女性身体伤害，一定要注意科学用药。如果遇到这些不良反应，可以考虑停止用药或者减少药物剂量。虽然诺雷德功效比较强，治疗疾病效果显著，但使用时也要小心谨慎，不宜滥用药物。
